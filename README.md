## Objectif
Nettoyer un jeu de données et analyser sa qualité.

## Compétences développées
- Data cleaning
- Analyse univariée et multivariée
- Détection d’anomalies

## Outils
- Python
- Pandas
- Seaborn

## Livrables
- Notebook de nettoyage
- Analyse des incohérences

## Résultats
Identification des incohérences et traitement cohérent des données.
